23. Interview questions

These are the questions interviewers use to see whether the concepts in this book are available when you speak. Each one has the point of the question and an answer you can say aloud. A strong answer is short, then one example, then the trap if there is one. You do not need to recite the paragraph.

Names and objects

What is the difference between is and ==? == asks whether the values compare equal. is asks whether both names point at the same object. Use is for None. Two lists with the same items are == and are not is.

Are arguments passed by value or by reference? Neither, in the C++ sense. The parameter name is stuck on the same object the caller passed. Reassigning the parameter moves only the local label. Mutating the object, such as append, is visible to the caller because there is one object.

What is mutable and what is immutable? Immutable: int, float, str, tuple, frozenset, bytes. Mutable: list, dict, set, bytearray, and most class instances. Immutability is why strings and tuples can be dict keys and why “changing” an int actually binds a new object.

Why did changing one list change another? Both names were labels on one list. Assignment does not copy. A shallow copy copies the outer list and still shares the inner objects. copy.deepcopy copies the inners too.

What does a, b = b, a do? The right side builds a tuple of the current values, then the left side unpacks it. No temporary variable is required.

Types and text

Why is 0.1 + 0.2 not 0.3? Floats are binary fractions with limited bits. Those decimals are not exact in binary. For money, use decimal.Decimal constructed from strings.

What is the difference between str and bytes? str is Unicode text. bytes is raw octets. Convert with encode and decode, usually UTF-8. You cannot mix them with +.

How do you join many strings? " ".join(parts). Repeated += in a loop builds many intermediate strings. Join walks the pieces once.

What is an f-string? A string literal with expressions in braces, evaluated when that line runs: f"{name} scored {score}".

Which values are false? None, False, numeric zero, and empty containers and strings. An empty list is false and is not None. Test absence with is None.

Collections

When do you pick a list, a tuple, a dict, or a set? A list is an ordered collection you edit. A tuple is a fixed record. A dict is a lookup by key. A set is unique items with fast membership. Dict keys and set items must be hashable.

Why can a tuple be a dict key while a list cannot? A key’s hash must stay stable. A list can change after insertion, so it is unhashable. A tuple is hashable only when every item inside it is hashable.

Are dicts ordered? Yes. Since Python 3.7, insertion order is part of the language. That does not make a dict a priority queue. Use heapq when you always need the smallest item.

What is the cost of in? Average constant time for a dict or a set. Linear for a list or a tuple, because those are scanned.

What do append and insert(0, x) cost? Append is amortized constant time. Insert at the front moves every later item, so it is linear. A queue that grows at both ends wants collections.deque.

list versus tuple in an interview sentence. Same indexing and slicing. A list can grow and change slots. A tuple cannot, so it can be a key and it signals a fixed shape.

What does sorted return, and what does list.sort return? sorted returns a new list. list.sort sorts in place and returns None. Both take key and reverse. Python’s sort is stable: equal keys keep their original order.

Control flow and functions

What is a default-argument bug? Defaults are created once, at definition. def add(item, bucket=[]) shares one list across calls. Use bucket=None and create a new list inside the function.

What are *args and **kwargs? *args collects extra positional arguments into a tuple. **kwargs collects extra keyword arguments into a dict. In a call, *seq and **mapping unpack outward.

What is LEGB? The lookup order for a name: local, enclosing function, global module, builtin. Assignment inside a function makes the name local for the whole function. global and nonlocal are how you assign further out.

What is a closure? A function that uses variables from the function that created it, after that outer call has returned. In a loop, every lambda sees the final value of the loop variable unless you bind the current value as a default: lambda i=i: i.

What is the else on a for loop? It runs when the loop ended without break. It is the “not found” branch of a search.

What does // do? Floor division. It divides and rounds toward negative infinity, which is not the same as truncating toward zero for negative numbers.

Classes

What is self? The instance the method was called on. You declare it as the first parameter. The call obj.method() passes obj in for you.

@classmethod versus @staticmethod versus a normal method. A normal method receives the instance. A classmethod receives the class, which is how alternate constructors stay correct for subclasses. A staticmethod receives neither. If it does not need the class, a module-level function is often clearer.

What is @property? A method that callers read like an attribute. Use it when a stored field later becomes a calculation and you do not want to change every caller.

__str__ versus __repr__. __repr__ is the unambiguous developer form, ideally enough to see how the value was built. __str__ is the friendly form print prefers. If only __repr__ exists, print uses it.

__init__ versus __new__. __new__ creates the instance and is the place to intervene for immutables such as tuple subclasses. __init__ initializes an instance that already exists. Almost every class you write only needs __init__.

What is the MRO? The method resolution order: the sequence of classes Python searches for an attribute. Single inheritance is a straight line. Multiple inheritance uses the C3 order. Read Class.__mro__ when super() surprises you.

What does a leading underscore mean? _name means internal by convention. __name is mangled to _Class__name so a subclass does not override it by accident. Neither one is a security barrier.

Why a dataclass? The class mostly stores fields. The decorator writes __init__, __repr__, and __eq__. frozen=True makes instances hashable if the fields are hashable.

What is duck typing? If an object has the methods you call, it is acceptable. You do not require a particular base class. A Protocol is that idea written down for a type checker.

Errors, files, and with

What runs in try, except, else, and finally? try is the risky work. except handles a matching exception. else runs only when try did not raise. finally runs in every case, including after a return, and is where you release a resource if you are not using with.

Why avoid a bare except:? It also catches KeyboardInterrupt and SystemExit, which inherit from BaseException, not Exception. Catch the type you can handle.

What is EAFP? Easier to ask forgiveness than permission. Try the operation and catch KeyError or FileNotFoundError. A check followed by the action can still fail if something changes in between.

What does with guarantee? __enter__ runs at the start and __exit__ runs when the block ends, including when it raises or returns. That is why files are opened with with. Always pass encoding for text.

What is if __name__ == "__main__"? That block runs only when the file is started directly. Importing the file sets __name__ to the module name, so the program does not start as a side effect of the import. On Windows, multiprocessing needs this guard.

Iterators, generators, and decorators

Iterable versus iterator. An iterable can produce an iterator, which a for loop does for you. An iterator remembers its position and returns the next item until it raises StopIteration. A list is iterable. Calling iter on it gives an iterator.

Why a generator? yield produces one item at a time and pauses. A large file or a long range does not become one giant list. Calling the generator function does not run the body. It returns the generator. A generator expression is spent after one walk.

List comprehension versus generator expression. Square brackets build the whole list now. Parentheses build a generator that computes on demand. Use the list when you need length, indexing, or several walks.

What is a decorator? A function that takes a function and returns a function. @deco above def is the same as fn = deco(fn) after the definition. Use functools.wraps so the wrapper keeps the original name and docstring.

What does functools.lru_cache assume? The function is pure: the same arguments always mean the same result, and the work is worth storing. A cached function that reads the clock or a global returns a stale answer.

Modules and types

What is a virtual environment? A private folder of third-party packages for one project, so two projects can depend on different versions. Create it with python -m venv .venv and install with the pip inside it.

Do type hints change runtime behavior? No. The interpreter does not enforce them. A type checker such as pyright or mypy reads them as a separate step. str | None means a string or None.

What is a Protocol? A structural type. Any object with the listed methods matches, even with no shared base class. That is duck typing for the checker.

Concurrency

What is the GIL? In CPython, a lock that allows one thread to run Python bytecode at a time. Threads still help for waiting on network or disk, because that waiting releases the lock. A pure Python CPU loop does not get faster with more threads. Use processes, or native code that releases the lock, for CPU work.

Thread, process, or asyncio? Threads for blocking I/O with ordinary libraries. Processes for CPU-bound Python. Asyncio for many concurrent sockets in one thread, using libraries that await. A blocking call inside async def freezes the loop.

Is n = n + 1 safe across threads? No. Two threads can read the same n and both write the same next value. Use a lock, or do not share the variable. List append of one item is a different, simpler operation. Do not generalize from it.

What is a race? Two threads use the same data, the result depends on the order they run, and that order is not fixed. The fix is not to share, or to make the critical update atomic with a lock or a queue.

Short coding questions

Say the idea first, then write it. Handle the empty input aloud so the interviewer hears that you thought about it.

Count words in a file, case-insensitive. Open with pathlib or with, walk lines, split, and add to a Counter after lower. Do not read a huge file as one string if line-by-line works.

from collections import Counter
from pathlib import Path

def word_counts(path):
    counts = Counter()
    text = Path(path).read_text(encoding="utf-8")
    for word in text.lower().split():
        counts[word] += 1
    return counts

Find the first repeated character. Walk the string with a set of characters already seen. The first character already in the set is the answer. If the loop ends, there is no repeat. This is linear time and uses memory proportional to the alphabet you actually saw.

def first_repeat(text):
    seen = set()
    for char in text:
        if char in seen:
            return char
        seen.add(char)
    return None

Group words that are anagrams. The key is the letters in sorted order. A dict of lists collects words that share a key.

def group_anagrams(words):
    groups = {}
    for word in words:
        key = "".join(sorted(word))
        groups.setdefault(key, []).append(word)
    return list(groups.values())

Two numbers in a list that add to a target. One pass, a dict from value already seen to its index. For each new number, ask whether target - number is already in the dict. Average linear time. Say what you return if no pair exists.

def two_sum(nums, target):
    seen = {}
    for index, num in enumerate(nums):
        need = target - num
        if need in seen:
            return seen[need], index
        seen[num] = index
    return None

Flatten one level of nested lists. A double comprehension or a loop that extends. Say whether deeper nesting is in scope. One level is [item for row in rows for item in row].

Remove duplicates and keep the first-seen order. A dict preserves insertion order. list(dict.fromkeys(items)) does it. A set would lose order.

Write a timer decorator. Take the function, return a wrapper that uses *args, **kwargs, records time around the call, and returns the original result. Apply functools.wraps.

import functools
import time

def timed(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        try:
            return func(*args, **kwargs)
        finally:
            elapsed = time.perf_counter() - start
            print(f"{func.__name__} took {elapsed:.4f}s")
    return wrapper

Implement a tiny LRU in words. A dict plus order. On get, move the key to the most recently used end. On put past capacity, drop the least recently used key. The book’s system-design volume has a full class. In a Python interview, describe those two structures and the two operations before you write the nodes.

Questions you can ask back

When they invite questions, pick one that shows you care how the code is maintained: how they test, how they pin dependencies, and whether CPU work and I/O work are separated in the service you would join. You are not proving you read a list. You are showing you know which concepts touch the job.

How to practice

  1. Cover the answer. Say yours out loud in under a minute.
  2. Uncover and keep only the sentence you missed.
  3. For each coding question, write it in a file and run it, including the empty input and a one-item input.
  4. Stop when you can answer the GIL, the mutable default, is versus ==, a generator, and a decorator without looking. Those five separate people who have used Python from people who have read a list of keywords.
