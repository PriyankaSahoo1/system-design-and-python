Python from Zero

The concepts you should know. An offline guide.

This book is the concept map of Python. It assumes you can read a sentence and you have not memorized the language. Every idea is defined when it appears. The examples are Python 3.10 or newer. On this machine the installed interpreter is Python 3.14, which runs all of them.

Run a file with python file.py. Try a line in the prompt with python, then type exit() to leave. A concept is yours when you can predict the output before you run it.

1. Programs, indentation, and comments

A Python program is a text file of statements. The interpreter reads the file from top to bottom and runs each statement. Indentation is syntax. A block is the lines indented further than the line that opened them. Use four spaces. Do not mix tabs and spaces.

def greet(name):
    if name:
        print("Hello", name)
    else:
        print("Hello")

A comment starts with # and runs to the end of the line. The interpreter skips it. A docstring is a string sitting as the first statement of a module, function, or class. Tools and help() read it. Use a docstring to say what the function promises, not to narrate each line.

def area(width, height):
    """Return the area of a rectangle. width and height are numbers."""
    return width * height

print writes a line of text. It is how you look at a value while learning. In a real program, lasting messages go through the logging module, covered later.

2. Objects, names, and mutability

Everything in Python is an object: a thing with a type, an identity, and a value. The number 3, the text "hi", a list, and a function are all objects.

A name is a label stuck on an object. Assignment sticks the label on.

count = 1
count = count + 1

The second line builds a new integer and moves the label count onto it. It does not change the object 1. Integers cannot change. They are immutable.

A list can change. It is mutable.

nums = [1, 2]
also = nums
also.append(3)
# nums and also are the same list: [1, 2, 3]

also = nums does not copy the list. Both names point at one object. append changes that object, so both names see the change. This is the fact behind most “why did my other variable change?” bugs.

== asks whether two values compare equal. is asks whether two names point at the exact same object. Use is for None and for this identity question. Use == for values.

a = [1, 2]
b = [1, 2]
a == b      # True, same contents
a is b      # False, two lists

A shallow copy makes a new outer container and keeps the same inner objects. A deep copy copies the inners too. list(old), old[:], and copy.copy are shallow. copy.deepcopy walks the whole structure.

import copy
grid = [[1], [2]]
shallow = copy.copy(grid)
shallow[0].append(9)
# grid is now [[1, 9], [2]] because the inner list was shared
deep = copy.deepcopy(grid)
deep[0].append(8)
# grid is unchanged by this append

3. None, Booleans, and numbers

None is the single object that means “no value.” There is only one of it. Test with result is None.

Booleans are True and False. They are the two values of type bool.

Integers (int) have no fixed size. 2 ** 1000 is a real integer, not an overflow. Floats (float) are binary fractions with a limited number of bits. 0.1 + 0.2 is not exactly 0.3. For money and other exact decimals, use decimal.Decimal, not float.

from decimal import Decimal
price = Decimal("19.99")
tax = Decimal("0.08")
total = price * (1 + tax)

Write the decimal as a string. Decimal(0.1) starts from the already-inexact float.

Division with / always returns a float. // is floor division, toward negative infinity. % is the remainder. divmod(a, b) returns both. ** is power.

round uses banker’s rounding on ties: round(2.5) is 2 and round(3.5) is 4, rounding to the even integer. Do not use it as a money policy. Quantize a Decimal instead.

4. Text and bytes

A str is Unicode text. A bytes object is raw octets. Text becomes bytes through an encoding, usually UTF-8.

text = "café"
raw = text.encode("utf-8")   # bytes
back = raw.decode("utf-8")    # str

Strings are immutable. Methods such as upper and replace return a new string. Useful tests: startswith, endswith, isdigit, strip. split breaks a string into a list. join builds a string from pieces and is the right way to combine many fragments.

words = ["system", "design"]
line = " ".join(words)        # "system design"

Indexing starts at 0. A negative index counts from the end. s[-1] is the last character. A slice s[start:stop] includes start and excludes stop. s[::2] takes every second character. Slicing a string returns a new string.

Formatting: an f-string evaluates expressions inside braces.

name = "Priya"
score = 9
label = f"{name} scored {score}"

Put a format spec after a colon: f"{price:.2f}". For a value that might contain braces or comes from a template file, template.format(name=name) is the other tool. Do not build SQL or HTML by gluing raw user text into a string.

A raw string, r"\n", treats backslashes as ordinary characters. Regular expressions want raw strings so \d stays \d.

5. Operators and truth

Comparisons chain: 0 <= n < 10 means 0 <= n and n < 10, and n is evaluated once.

and, or, and not combine conditions. and and or return one of their operands, not always a Boolean.

name = "" or "guest"     # "guest"
found = items and items[0]

Many values count as false in an if: None, False, 0, 0.0, empty text, empty bytes, and empty containers. Everything else counts as true. If you mean “is this missing,” write value is None. An empty list is false and is not None.

Membership is in. For a dict, in tests keys. For a string, it tests a substring. For a set or dict, the test is fast. For a list, the test walks the list.

The walrus operator := assigns inside an expression.

if (line := input()) != "quit":
    print(line)

Use it when a name would otherwise be assigned on the line above only so the next line can test it.

6. Choices and loops

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"

if runs its block when the condition is true. elif is another condition, tried only if the earlier ones were false. else runs when none matched. One of these blocks runs.

match compares a value against patterns. It fits when one value has several shapes.

def describe(value):
    match value:
        case 0:
            return "zero"
        case [x, y]:
            return f"pair {x}, {y}"
        case {"code": code}:
            return f"code {code}"
        case _:
            return "other"

A for loop asks an iterable for items, one at a time.

for item in ["a", "b"]:
    print(item)

range(stop) yields integers from 0 up to but not including stop. range(start, stop, step) is the full form. range does not build a giant list.

while repeats as long as a condition stays true. If the condition never becomes false, the loop never ends. That is an infinite loop. Put a change inside the body that moves toward the end.

break leaves the loop now. continue skips the rest of this round and starts the next. A loop may have an else. That else runs when the loop finished without break. It is useful for search: “we walked the whole list and did not find it.”

for user in users:
    if user.name == "Priya":
        break
else:
    user = None

7. Functions and scope

A function packages steps under a name. return sends a value back and ends the function. A function with no return returns None.

def clamp(n, low, high):
    if n < low:
        return low
    if n > high:
        return high
    return n

Parameters can have defaults. The default is computed once, when the function is defined, not on each call. A mutable default is shared by every caller that omits the argument. That is a classic bug.

def add_item(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket

Arguments can be passed by position or by name. A / in the parameter list means “everything before me is positional only.” A * means “everything after me is keyword only.”

def build(name, /, size, *, bold=False):
    return name, size, bold

build("title", 12, bold=True)

*args collects extra positional arguments into a tuple. **kwargs collects extra keyword arguments into a dict.

def show(*args, **kwargs):
    return args, kwargs

show(1, 2, color="blue")   # ((1, 2), {"color": "blue"})

A lambda is a function written as one expression. Use it as a tiny key or callback. If the body needs statements, write a def.

names = ["priya", "Anu", "ben"]
ordered = sorted(names, key=lambda s: s.lower())

Scope

A name is looked up in the LEGB order: Local to the function, then Enclosing functions, then the module Global, then Builtins such as len and print.

Assignment inside a function makes that name local to the whole function. To assign to a module name, declare global. To assign to a name in an enclosing function, declare nonlocal. Reading a global needs no declaration.

A closure is a function that remembers variables from the function that built it.

def make_adder(n):
    def add(x):
        return x + n
    return add

add5 = make_adder(5)
add5(2)     # 7

The loop-closure trap: every lambda in this list sees the same i, which is 2 after the loop.

funcs = []
for i in range(3):
    funcs.append(lambda: i)
# each funcs[k]() returns 2

funcs = []
for i in range(3):
    funcs.append(lambda i=i: i)
# default binds the current i: 0, 1, 2

8. Lists, tuples, dicts, and sets

A list is an ordered, mutable sequence. Indexing is fast. Appending at the end is fast on average. Inserting at the front is slow, because every later item moves. Searching with in walks the list.

nums = [3, 1, 2]
nums.append(4)
nums.sort()
last = nums.pop()

sort changes the list. sorted(nums) returns a new list and leaves the original. Both take key and reverse.

A tuple is an ordered, immutable sequence. Use it for a fixed record, such as a point (x, y), and as a dict key when every item inside is hashable. Immutable means you cannot rebind a slot. If a slot holds a list, that list can still change.

A dict maps keys to values. Keys must be hashable: immutable values such as strings, numbers, and tuples of hashables. Lists cannot be keys. Lookup, insert, and delete are fast on average. Since Python 3.7, dicts keep insertion order.

user = {"name": "Priya", "score": 9}
user["city"] = "Pune"
score = user.get("score", 0)
name = user.pop("name")

user["missing"] raises KeyError. user.get("missing") returns None or a default you pass. Iterate keys with for key in user, pairs with user.items().

A set holds unique hashable items and does not keep a useful order for your logic. It gives fast membership and the operations | union, & intersection, and - difference.

seen = set()
seen.add("a")
"a" in seen

A frozenset is an immutable set and can be a dict key.

9. Comprehensions and unpacking

A comprehension builds a list, set, or dict from a loop written as an expression. It is the ordinary way to transform a sequence.

squares = [n * n for n in range(5)]
evens = [n for n in range(10) if n % 2 == 0]
index = {name: i for i, name in enumerate(names)}
unique_sizes = {len(word) for word in words}

enumerate pairs each item with its index. zip walks several sequences together and stops at the shortest.

for i, name in enumerate(["a", "b"]):
    print(i, name)
pairs = list(zip([1, 2], ["a", "b"]))

Unpacking assigns several names at once.

x, y = (1, 2)
first, *rest = [1, 2, 3, 4]
a, b = b, a

The last line swaps without a temporary variable. *rest collects whatever remains into a list. You can unpack into a call: print(*nums) passes each item as its own argument, and f(**options) passes a dict as keyword arguments.

10. Files and paths

Use pathlib.Path for file names. It joins pieces with / in code, on every operating system.

from pathlib import Path
folder = Path("notes")
folder.mkdir(exist_ok=True)
path = folder / "today.txt"
path.write_text("hello\n", encoding="utf-8")
text = path.read_text(encoding="utf-8")

open is the lower-level tool. Always pass encoding for text. A with block closes the file even if an error happens.

with open(path, encoding="utf-8") as handle:
    for line in handle:
        print(line.rstrip("\n"))

Modes: "r" read text, "w" write text and truncate, "a" append, "rb" and "wb" for bytes. "w" destroys existing contents when the file opens. Read bytes when the file is an image, a zip, or anything that is not text.

JSON is the usual text format for structured data.

import json
payload = json.dumps({"ok": True})
data = json.loads(payload)
path.write_text(json.dumps(data), encoding="utf-8")

json understands dicts, lists, strings, numbers, Booleans, and None. It does not understand a custom class unless you convert that class to those types first.
